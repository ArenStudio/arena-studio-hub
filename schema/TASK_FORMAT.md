# Формат задачи

Задача — файл Markdown с обязательной шапкой. Поля читаются машинно,
поэтому имена и порядок менять нельзя.

```yaml
---
id: GP-001
role: GP
status: READY          # BACKLOG | READY | IN_PROGRESS | REVIEW | QA | DONE
project: TESTBED-01
reviewers: [QA, TECH]
created: 2026-08-11
---
```

## Обязательные разделы

**ЦЕЛЬ.** Одно предложение: что должно существовать после выполнения.

**КРИТЕРИИ ПРИЁМКИ.** Пронумерованный список проверяемых утверждений.
Каждый критерий формулируется так, чтобы проверяющий мог ответить
только «да» или «нет». Формулировки вида «сделать хорошо» запрещены.

**РАЗРЕШЁННЫЕ ФАЙЛЫ.** Точный список путей, которые агент вправе
создать или изменить. Всё остальное — запрещено.

**ЗАПРЕЩЕНО.** Явные границы: чего агент не делает даже при
уверенности, что так лучше.

**ART-001.** Для задач с визуальной частью — напоминание о запрете
генеративных ассетов и требование журнала происхождения.

## Правило статусов

READY и DONE назначает только PROD. Агент может перевести задачу из
READY в IN_PROGRESS и из IN_PROGRESS в REVIEW. Самостоятельное
закрытие задачи агентом не принимается ни при каких обстоятельствах.
