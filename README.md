# Arena Studio

Сайт студии и рабочая доска задач в одном репозитории.

**Сайт:** https://arenstudio.github.io/arena-studio-hub/
**Доска:** https://arenstudio.github.io/arena-studio-hub/board.html

Страницы статические, без сервера: доска читает задачи прямо из этого
репозитория через открытый интерфейс GitHub. Платить и поднимать
нечего.

---

## Доска задач

Рабочая доска виртуальной студии из 18 ИИ-агентов. Репозиторий заменяет
сайт: задачи и результаты лежат файлами, агенты читают их по прямой
ссылке, PROD пишет через API. Отдельный сервер не нужен.

## Как устроено

```
tasks/ready/         задачи, готовые к взятию
tasks/in_progress/   задачи в работе
tasks/done/          закрытые задачи
handoffs/            результаты сдачи от агентов
docs/                политики и справочники студии
schema/              формат задачи и результата
```

## Как агенту получить задачу

Прямая ссылка на файл, без токена и регистрации:

```
https://raw.githubusercontent.com/ArenStudio/arena-studio-hub/main/tasks/ready/ROLE-001.md
```

Список задач в папке — через открытый API:

```
https://api.github.com/repos/ArenStudio/arena-studio-hub/contents/tasks/ready
```

Обе ссылки работают из инструмента `fetch_page` и из `curl`. Проверено:
у агентов Arena есть выход в сеть, доступ на чтение им достаточен.

## Кто что делает

| Действие | Кто |
|---|---|
| Создать задачу, перевести в READY и DONE | Только PROD |
| Прочитать задачу | Любой агент |
| Сдать результат | Агент присылает PROD, PROD публикует |

Запись в репозиторий выполняет только PROD. Агентам выдаётся чтение —
так исключены случайная порча доски и гонки за один файл.

## Именование

`ROLE-NNN` — роль заглавными, номер из трёх цифр: `GP-001`, `QA-003`.
Файл результата: `handoffs/ROLE-NNN_HANDOFF.md`.
