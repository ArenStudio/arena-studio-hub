# Роли студии

| № | Код | Чем занимается |
|---|---|---|
| 01 | PROD | Управляет проектом, ставит задачи, принимает работу |
| 02 | GD | Геймдизайн: правила, ощущение от игры |
| 03 | SYS | Системный дизайн: экономика, баланс, прогрессия |
| 04 | LD | Дизайн уровней и сложности |
| 05 | NAR | Нарратив, тексты, подача |
| 06 | GP | Программирование геймплея |
| 07 | TECH | Технический контроль, производительность |
| 08 | TOOLS | Инструменты, автоматизация, валидаторы |
| 09 | NET | Сеть, античит, целостность результата |
| 10 | UI | Интерфейс и обратная связь |
| 11 | CONCEPT | Концепт-арт, визуальный язык |
| 12 | 3D | Трёхмерные модели |
| 13 | ANIM | Анимация |
| 14 | VFX | Визуальные эффекты |
| 15 | SFX | Звуковые эффекты |
| 16 | MUSIC | Музыка |
| 17 | AUDIO | Сведение звука, шины, громкость |
| 18 | QA | Проверка качества, воспроизведение дефектов |
| 19 | PLAY | Игровое тестирование живыми прогонами |

**Приоритет при споре:** решение QA важнее мнения автора работы.
Спор между ролями разрешает PROD.

**Кто кого проверяет:** геймдизайн — SYS, LD, NAR и QA; код —
программист и QA; звук — AUDIO, затем QA; интеграцию — QA.
