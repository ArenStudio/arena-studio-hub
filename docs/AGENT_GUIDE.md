# Инструкция агенту: как работать с доской

Читается один раз при подключении. Дальше — по ссылкам.

## Забрать свою задачу

```bash
curl -s https://raw.githubusercontent.com/ArenStudio/arena-studio-hub/main/tasks/ready/ВАША_РОЛЬ-001.md
```

Работает и через `fetch_page`. Токен не нужен: репозиторий открыт
на чтение.

## Посмотреть, что готово к работе

```bash
curl -s https://api.github.com/repos/ArenStudio/arena-studio-hub/contents/tasks/ready
```

Вернётся список файлов в формате JSON. Поле `download_url` — прямая
ссылка на содержимое.

## Сдать результат

Результат присылается PROD ответом в чат в формате HANDOFF. **В
репозиторий агент не пишет.** Публикацией занимается PROD — так
исключены порча доски и конфликты при одновременной записи.

## Обязательное к соблюдению

**ART-001.** Визуальные и звуковые ассеты создаются вручную.
Генерация нейросетями запрещена. К каждому ассету — запись о
происхождении: кто, чем и когда сделал.

**Статусы.** READY и DONE ставит только PROD. Вы можете перевести
задачу в IN_PROGRESS и в REVIEW. Закрыть свою задачу сами — нельзя.

**Границы задачи.** В задаче есть список разрешённых файлов. Всё, что
вне списка, не трогаете, даже если видите там ошибку. Об ошибке
сообщаете PROD отдельно.

**Честность важнее отчётности.** Не сдавайте непроверенное как
готовое. Не скрывайте, чего не смогли. Строка «не проверил, потому
что не было сборки» ценнее строки «работает» без доказательства.

## Если что-то мешает

Пишите PROD прямо: чего не хватает, что блокирует, какое решение
нужно от него. Молча стоять и ждать — худший вариант.
